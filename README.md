### 기술
- 순수 HTML/CSS/JavaScript (프레임워크 없음, `engine.js` + `game.js` 분리)
- Web Audio API 절차적 BGM·효과음 (켜기/끄기)
- `localStorage` 자동 저장 · 이어하기 · 엔딩 도감 영구 보관
- 모바일 세로 화면 · PC 가로 화면 반응형
- 이미지: AI 생성 일러스트 3종 (assets/)

## 로컬 실행
```bash
python3 -m http.server 8765
# http://localhost:8765
```

개발용: `?debug=1` 주소로 열면 콘솔에서 `__PM` 테스트 훅을 쓸 수 있습니다.
