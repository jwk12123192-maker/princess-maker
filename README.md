### 딸의 마음 (핵심 시스템)
- **숨은 성향 6종**: 탐구형 · 예술형 · 사교형 · 활동형 · 반항기 · 다정형 (플레이하며 서서히 드러남)

- **조건부 이중생활**: 유대감이 낮고 스트레스가 쌓이며 싫어하는 활동을 계속 강요할 때만 일탈도가 쌓입니다. 바르게 키우면 일탈도는 0에 머뭅니다.
  - 땡땡이(학원 대신 PC방·친구·몰래 쉬기), 뒷계정, 몰래 돈 쓰기
  - 학원 결석 문자·지인 제보·카드 내역·길에서 목격 등 **발각 이벤트** → 단호한 훈육 vs 속마음 듣기
- **실시간 성격 칭호**: 스탯·유대감·스트레스·일탈도 조합으로 '겉과 속이 다른 아이', '지친 완벽주의자', '당찬 야망가' 등 19종이 동적으로 결정되고, 변화는 결과 화면 배너와 **성장 일기** 타임라인에 기록됩니다.

## 기술
- 순수 HTML/CSS/JavaScript (`engine.js` 게임 로직 + `game.js` UI + `lock.js` 잠금)
- 4자리 PIN 잠금: 솔트 + SHA-256 해시(Web Crypto), 미지원 환경은 FNV-1a 폴백, `sessionStorage`로 세션 유지
- Web Audio API 절차적 BGM·효과음 (켜기/끄기)
- `localStorage` 자동 저장 · 이어하기 · 엔딩 도감 영구 보관
- 모바일 세로 화면 · PC 가로 화면 반응형
- 이미지: AI 생성 일러스트 3종 (`assets/`)
